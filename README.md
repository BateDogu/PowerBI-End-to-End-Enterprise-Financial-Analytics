 📊 Power BI End-to-End Enterprise Financial Analytics

 📌 Project Overview
This repository contains a comprehensive, end-to-end Power BI financial analytics dashboard designed for enterprise performance monitoring, budget control, capital expenditure tracking, and working capital analysis.

 🛠️ Data Model & Tech Stack
* BI Tool: Power BI Desktop
* Data Modeling: Star Schema architecture, dimensional modeling
* Calculations: Advanced DAX measures for YTD, YoY, Variance Analysis, and Financial Ratios
* Security: Dynamic Row-Level Security (RLS) configured for regional/departmental access control
